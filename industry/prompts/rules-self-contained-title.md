
【标题自洽规则 — 让读者不点开就知道"这是关于谁的什么事"】

1. 标题必须点出核心主体：平台名 / 品牌名 / 公司名 / 项目名。
2. 原标题已经清楚点出主体的：英文标题翻译成中文、中文标题保持原意，不要为改写而改写。
3. 原标题只是没信息量的 teaser（如 "重磅"、"官宣"、"变了"、"定了"）时，结合【来源】和正文把主体补进标题。例：原标题 "官宣" + 来源 "淘宝规则中心" → "淘宝官宣调整仅退款规则"。
4. 补主体只能用【来源】或正文里真实出现的名字。正文和来源都没点出具体平台/品牌时，用上位词（如"电商平台""跨境电商平台"）兜底，绝不凭"行业常识"编一个具体平台 / 品牌 / 数字。
5. 原标题表达的【文章类型和核心动作】是硬边界：How / Why / Guide / Analysis / Review 这类解释、分析、教程或评测标题，中文标题必须保留这个类型；不能因为正文谈到一个已经存在的平台、品牌或规则，就改写成"发布 / 推出 / 上线 / 官宣"。只有原标题明确宣布了发布、推出、上线或官宣，中文标题才能使用对应动作。保留文章类型不等于删主体：仍须按第 1-4 条补全正文或来源明确给出的平台、品牌、项目名。
   例：原标题 "How Temu's semi-managed model works" → "Temu 半托管模式如何运作"，不能写成 "Temu 上线半托管"。
   例：原标题 "How to 报名平台的流量激励计划" + 来源和正文明确是抖音电商 → "抖音电商如何报名流量激励计划"，不能只写成缺主体的 "如何报名流量激励计划"。
6. 本条的动作和背景里的旧发布要分清：原文把发布写成过去的事（"在上周的商家大会上，我们宣布了…""上周我们上线了…"），本条是在讲用法、做解读或再次推广时，标题写介绍、解读或讲解，把发布交代成此前的事；不能写成"推出 / 发布 / 上线"，否则读者会当成今天的新闻。只有原文明确某项规则或功能是现在才开放或新增，才对那一项用对应动作。
   例：正文 "在上周的商家大会上，我们宣布了新的流量激励计划，今天介绍报名方式" → "某平台介绍商家大会宣布的流量激励计划报名方式"，不能写成 "某平台推出流量激励计划"。
