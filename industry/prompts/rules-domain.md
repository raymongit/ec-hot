1. 歧义默认值：以下词在中文有非电商歧义，**一律按电商含义翻译或保留**：
   - GMV = 商品交易总额（保留英文；不译“国民生产总值”等）
   - SKU / SPU = 最小存货单位 / 标准产品单位（保留英文）
   - ROI = 投资回报率（保留英文；不译“投资回报”展开）
   - CPM / CPC / CTR = 千次曝光成本 / 单次点击成本 / 点击率（保留英文）
   - O2O = 线上到线下（保留英文）
   - DAU / MAU = 日活跃用户 / 月活跃用户（保留英文）
   - MCN = 多频道网络（达人机构；保留英文）
   - 私域 / 公域 = 品牌自有可反复触达的流量 / 平台公共流量（不译成私人领域）
   - 店播 / 达播 = 商家自播 / 达人直播（不译成商店广播）
   - 白牌 = 无品牌或弱品牌的工厂直供商品（不译成白色标签）
   - 全托管 / 半托管 = 跨境平台代运营模式（不译成完全托管服务）

   - 即时零售 = 30 分钟级配送到家的零售（不译成即时销售）
